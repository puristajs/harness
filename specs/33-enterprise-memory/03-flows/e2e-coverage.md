## Operational paths

- Cancellation is tested during embedding, engine query, summary generation, and indexed write. Aborted work produces no later engine mutation.
- Timeout uses existing model timeout semantics and engine client command/query timeout options.
- Recovery from descriptor mismatch is explicit reindex into the documented namespace; no automatic destructive migration occurs.
- Data deletion removes record, text index, vector index, and summary provenance in one engine operation.
- Expired records are excluded before list/search results. SQLite/PostgreSQL may be physically cleaned by operator SQL, Redis expires natively, NATS lazily deletes accessed values and relies on documented bucket limits for untouched values.
- PostgreSQL's no-container test path proves SQL behavior with PGlite/pgvector; release evidence separately proves real PostgreSQL pool, concurrency, planner, and extension behavior.
- Supply-chain verification covers direct dependency license, vulnerability scan, lockfile resolution, build provenance, and package contents.
- Documentation covers standalone Harness, PURISTA, testing, deployment, security/privacy, observability, migration, and capability comparison.
