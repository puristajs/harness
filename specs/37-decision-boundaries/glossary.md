# Glossary

- Decision: one allow/block/transform or governance effect evaluated at a named boundary.
- Evidence: safe source, occurrence-derived ID, phase and optional content-free reasonCode.
- Effective wire arguments: tool proposal after input rails, used for history/provider replay.
- Parsed input: once-normalized effective arguments shared by policy, approval and handler.
- Immediate approval: bounded approved/rejected callback for one tool occurrence.
- Durable review: application review state plus existing suspended wait and workflow replay.
- Claim: immutable application admission of a reviewed action to one execution ID.
- Receipt: application proof returned idempotently for that execution ID.
- D0/D1: mechanical work/private implementation arrangement; neither permits new public behavior.
