# Glossary

- **Policy configuration:** data selecting ordered action IDs and sensitive-data policy; no executable behavior.
- **Action definition:** contextually typed callback and declared dependencies supplied to the constructor.
- **Action token:** immutable phase-bearing handle to the addon's private prepared executor.
- **Preflight:** existing parse, compile and build checks before an invocation, not a separate runtime engine.
- **Schema preservation:** parsing a rail value must preserve its JSON structure; narrowing is permitted, normalization is not.
- **Registered native tool:** canonical tool definition constructed by the builder-local generic helper.
